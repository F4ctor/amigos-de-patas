# Painel administrativo

Com o projeto em `AMPPS/www/ong_adocao`, acesse:

```text
http://localhost/ong_adocao/painel_admin/login.html
```

Credenciais iniciais:

```text
E-mail: admin@ong.local
Senha: Admin@123
```

O painel utiliza a API localizada em `../backend_api` e deve ser aberto pelo Apache do AMPPS, não diretamente como arquivo local.
