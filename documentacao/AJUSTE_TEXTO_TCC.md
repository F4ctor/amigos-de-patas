# Texto sugerido para atualizar a seção de viabilidade técnica

No plano técnico, a solução utiliza o framework Flutter e a linguagem Dart para o desenvolvimento do aplicativo mobile Android. A persistência das informações é realizada em banco de dados relacional PostgreSQL, acessado por meio de uma API REST desenvolvida em PHP. O sistema também dispõe de um painel administrativo construído com HTML, CSS e JavaScript, destinado ao gerenciamento de animais, solicitações de adoção, campanhas de arrecadação, notícias, vídeos, usuários e informações institucionais. A comunicação entre o aplicativo, o painel e o servidor ocorre por requisições HTTP, com dados estruturados no formato JSON. Para a execução local e demonstração acadêmica, utiliza-se o AMPPS como ambiente local de servidor Apache, PHP e PostgreSQL.
